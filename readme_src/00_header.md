> [!IMPORTANT]
> **Honest status statement.** This repository describes an **academic working prototype**: a Raspberry Pi 5 kiosk that you can build, and a cloud archive design whose trust-critical rules are implemented and tested in `reference/`. It does **not** claim to own, digitise, host, or hold rights to every work associated with Dr. B. R. Ambedkar. It is **not** an installation at any institution, and no partnership with any institution is claimed or implied. The prototype's attract screen shows a venue label. That label is a placeholder; see [§ 69](#69-discrepancies-between-source-documents).
> Accessibility is **evaluated against** WCAG 2.2 AA as a design target. **No certified conformance** is claimed. Charts marked **TARGETS / ASSUMPTIONS** are planning values, not measurements. Charts marked **DEMO CORPUS** are computed from the 14-item sample embedded in the prototype and are **not** a representative evaluation of any archive.

> [!WARNING]
> **Historical content warning for builders.** The sample transcriptions, quotations, dates and page numbers in `prototype/ambedkar_kiosk.html` and `data/demo_corpus.json` are **placeholders for the prototype build**. Many are marked in the data itself as *"wording to be verified against the printed edition before production use."* Before any public demonstration, a curator, historian or librarian must replace or verify **every** title, exact quote, page identifier, date and media link. Engineers must not mark historical accuracy as reviewed themselves.

> [!NOTE]
> **Imagery policy.** The figures in this README are generated by Python (`scripts/generate_diagrams.py`) or captured from the running HTML prototype (`docs/screenshots/`). The historical photographs visible *inside* the prototype screenshots are embedded in the prototype file together with their credit lines. Their reuse in any new context needs its own rights review. No AI-generated image is ever indexed as historical evidence.

## ⚡ Quick Start

```bash
# 1. Clone (replace YOUR-ORG once the organisation is decided)
git clone https://github.com/YOUR-ORG/ambedkar-heritage-archive-main.git
cd ambedkar-heritage-archive-main

# 2. Open the working UI prototype. It is a single self-contained HTML file.
#    Any modern browser works. Use the left-edge "DEVICE CONSOLE" tab to simulate
#    the PIR sensor, the HOME button, Wi-Fi loss and the idle timeout.
xdg-open prototype/ambedkar_kiosk.html        # macOS: open ...  Windows: start ...

# 3. Run the reference rules and their tests (Python 3.10+, stdlib + pytest)
python -m venv .venv && . .venv/bin/activate
pip install -r requirements-docs.txt
python -m pytest reference -q                 # 46 passed

# 4. Rebuild every figure and this README
python scripts/generate_diagrams.py
python scripts/build_readme.py
```
